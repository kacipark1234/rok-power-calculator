Discord 分享用部署包

檔案：
- index.html：網站主頁

GitHub Pages 部署：
1. 建立一個新的 GitHub Repository。
2. 把 index.html 上傳到 Repository 根目錄。
3. 進入 Repository 的 Settings。
4. 左側選 Pages。
5. Build and deployment 選 Deploy from a branch。
6. Branch 選 main，資料夾選 /(root)。
7. 儲存後等待 GitHub 產生網站網址。
8. 把網址貼到 Discord 即可。

這個版本是純前端 HTML，不需要伺服器或資料庫。
